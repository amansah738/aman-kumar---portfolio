## 🌟 Key Features

- **Cyber Aesthetic UI**: Custom obsidian theme, 4 dynamic cyber accents (Matrix Emerald, Electric Cyan, Quantum Violet, Solar Amber), and iconic Matrix digital rain mode.
- **Interactive Security Playground**: Real-time password entropy & crack-time estimator, plus live XSS/SQLi payload sanitizer.
- **CLI Terminal Shell (`aman.sh`)**: Built-in interactive keyboard-driven shell (`Ctrl+K`) with 10+ custom cyber commands.
- **Competitive Programming & DSA Telemetry**: Live problem-solving analytics across LeetCode, GeeksforGeeks, HackerRank, and TryHackMe.
- **Instant Contact Card (vCard)**: Dynamic QR Code generator and 1-click `.vcf` mobile address book download.
- **Interactive Project Estimator**: Instant freelance and contract scope planner with direct WhatsApp and Email inquiry generation.
- **Web Audio Cyber SFX**: Zero-dependency procedural audio synthesized in real time via Web Audio API.

## 🚀 Quick Start (Run Locally)

### 1. Clone the repository
```bash
git clone https://github.com/amansah738/aman-kumar---portfolio.git
cd aman-kumar---portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:3000/` in your browser.

### 4. Build for production
```bash
npm run build
```
